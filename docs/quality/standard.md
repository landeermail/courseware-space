# 好课件六维标准

本标准评估课件在物理正确之后，是否真正帮助学生建立题目文字和静态图难以传达的时空、因果与解题理解。物理正确性是进入本标准的前置闸门，由物理断言和老师确认负责，不计入六维得分。

评价采用“机器判结构 + 老师判呈现”的组合方式：当前先用机器确认必要结构是否存在，由老师判断这些结构是否真的促进理解；积累稳定反馈后，再逐维把可复用的老师判据转成机器检查。

## 1. 因果呈现

**定义**：学生能看见一个物理量或状态的改变，如何引起后续量和状态依次变化。

**老师判据**：

- 页面是否把“起因—中间机制—结果”连接起来，而不是并列展示若干结论。
- 学生改变上游条件后，能否沿同一条链追踪方向、大小或状态的变化。
- 文字、箭头、读数与动画是否表达同一套因果关系。

**黄金样例实证**：

- `site/electromagnetism/q20-rotating-rod/index.html` 的“本题因果链”明确连接“OP 运动 → 产生电动势 → 回路电流 → CD 受力”；引导步骤继续让学生从电流方向推到安培力。
- `site/electromagnetism/q21-variable-field-rod-3d/index.html` 的 `causal-strip` 随阶段和位置更新；阶段 C 同时展示速度、电流、安培力过零与反向，避免把三个变化误看成无关事件。

**不及格表现**：只有公式或最终箭头；动画中的量会变，但学生不知道是谁导致谁；因果文字与模型状态不同步；把同时发生误写成因果关系。

**机器可判性**：当前可检查因果节点、连接关系和上游交互是否存在，也可检查状态变化后节点是否更新；暂时不能可靠判断节点选择是否抓住真正的认知难点。未来可从老师标注的“缺失环节”“错误连接”“无效节点”中形成领域因果图和回归样例。

## 2. 过程可见

**定义**：题目中不可直接观察的时间演化、方向变化和中间状态，被转化为可停留、可回看、可辨认的过程。

**老师判据**：

- 关键状态是否在合适的演示速度下清楚出现，而不是一闪而过。
- 转向、过零、临界、能量转移等中间事件是否能暂停或定位。
- 物理时间与演示时间是否区分，慢放是否改变观看速度而不篡改题设时间。
- 涉及力矢量时，方向和大小变化是否持续可辨认；力过零时是否能明确识别为零，而不是仍保留装饰性箭头。

> 判据修订来源：老师首评 `feedback-7d414bc2`，2026-07-30。

**黄金样例实证**：

- `site/electromagnetism/q20-rotating-rod/index.html` 第二问提供物理时间视图、慢放和阶段化状态，将“受力确定电流—电磁感应—能量结算”拆成可观察过程。
- `site/electromagnetism/q21-variable-field-rod-3d/index.html` 阶段 C 支持教学慢放和拖动时间，并在转向时显示“v、I、Fᴮ 同时为零”，返回时显示磁力总冲量回到零。

**不及格表现**：只播放一次完整动画；关键变化过快；只能看起点和终点；把演示耗时当成物理时间；靠大段旁白补充画面中不存在的过程。

**机器可判性**：当前可检查时间轴、暂停、回放、关键事件标记以及物理时间标签；也可验证关键时刻的模型状态。未来结合老师标注的“看不清时刻”和操作日志，学习哪些事件必须自动减速、停留或放大。

## 3. 有效交互

**定义**：学生改变与学习目标相关的条件或过程状态，并立即观察这一改变带来的物理后果。

**老师判据**：

- 交互是否服务于预测、比较、验证或纠错，而不只是播放、翻页和切换视角。
- 控件是否直接对应题目条件、关键变量或关键时刻。
- 操作结果是否反馈到模型、读数、因果链或图表，形成可理解的闭环。

**黄金样例实证**：

- `site/electromagnetism/q20-rotating-rod/index.html` 允许改变角速度并观察静止、上滑和下滑状态转变，也可独立显示或隐藏电流与受力以支持判断。
- `site/electromagnetism/q21-variable-field-rod-3d/index.html` 允许直接拖动导体棒或位置滑块，同步更新场景、因果节点和四张位置关系图；“比较同一位置 x=6”用于区分阶段 B 与 D。

**不及格表现**：唯一操作是播放；拖动物体只改变画面位置而不改变物理状态；控件很多但与学习目标无关；操作后没有可辨认反馈；触控设备无法完成主要操作。

**机器可判性**：当前可检查核心控件数量、触控尺寸、状态变化和模型输出是否联动，并区分播放控件与参数控件；暂时不能只凭控件数量判断教学价值。未来根据老师对每次交互“为什么有用”的分类，建立目标—变量—反馈闭环检查。

## 4. 任务驱动

**定义**：学生带着明确的观察、预测、操控或验证问题使用模型，而不是无目的地浏览动画。

**老师判据**：

- 页面是否告诉学生此刻要发现什么，而不是提前告诉答案。
- 任务是否要求学生做出判断、操作或比较，并能从模型获得回应。
- 引导顺序是否由认知需要决定；阶段限制是否有理由，且不会无谓阻断自由探究。

**黄金样例实证**：

- `site/electromagnetism/q20-rotating-rod/index.html` 用“观察—预测—电流—受力—探究”组织第一问，每步给出当前观察任务，并允许题目页签直接切换，不把阅读顺序当作强制锁。
- `site/electromagnetism/q21-variable-field-rod-3d/index.html` 各阶段动态更新“观察任务”；阶段 C 要求学生慢放或拖动时间，解释返回同一点时磁力冲量为何回到零。

**不及格表现**：页面按解答段落自动播放；任务只是“点击下一步”；问题和操作无关；先显示结论再让学生确认；所有题目被套进同一种固定流程。

**机器可判性**：当前可检查任务文本、对应操作和反馈目标是否同时存在，也可拒绝只有导航命令的伪任务；任务是否恰好击中学生困难仍需老师判断。未来从老师修改任务措辞和删留步骤的记录中归纳题型无关的任务模式。

## 5. 可验证性

**定义**：学生可以用可重复的操作、对照、读数或关系图检验自己的预测，而不是只能相信页面给出的结论。

**老师判据**：

- 是否有明确可比的预测量、观察量和判定条件。
- 同一结论能否通过改变参数、定位关键状态或建立对照重新检查。
- 模型是否展示足够证据，使学生能说清“为什么我的判断成立或不成立”。

**黄金样例实证**：

- `site/electromagnetism/q20-rotating-rod/index.html` 改变角速度后，模型同时显示受力与运动状态；静力平衡区间让学生验证安培力、重力分力和摩擦力的组合结果。
- `site/electromagnetism/q21-variable-field-rod-3d/index.html` 用“同一位置 x=6”的阶段 B/D 对照和速率、磁场、电动势、磁通量四张联动图验证“位置相同不代表电动势相同”；说明区给出每阶段的具体验证动作。

**不及格表现**：只标注“正确”；图表与场景不联动；读数无法回到同一条件复现；结论来自隐藏计算，学生看不到判定依据；比较对象同时改变多个无关条件。

**机器可判性**：当前可检查是否存在预测量、操作、观测量和明确判定关系，也可用物理模型验证数值一致性；比较设计是否控制住关键变量仍需要老师判断。未来积累老师选择的有效对照和无效对照，形成控制变量与证据充分性检查。

## 6. 与解题的衔接

**定义**：课件把直观观察重新连接到高三解题所需的对象、条件、规律、方程和答案判断，使理解能够落到纸笔推理并迁移到变式。

**老师判据**：

- 学生能否从模型识别研究对象、过程阶段、正方向、约束和已知量。
- 学生能否把观察到的因果关系翻译成适用规律与方程，而不是只记住动画外观。
- 学生能否用模型证据解释某个选项、数值或关系式为什么成立，并指出错误选项错在哪个条件或环节。
- 每个保留读数能否就地追溯到题设、定律常数、可操控可观察的模型状态或一步可达的推导，显示精度是否与推导链支持的有效位数一致。
- 相关读数是否被关系式串成从条件到结论的分析链，并实际服务于任务、判定或列式，而不是并列陈列精确数字。
- 改变非本质条件后，学生能否仍用相同因果骨架解题，而不是背当前题的按钮顺序。

> 判据修订来源：老师首评 `feedback-7d414bc2`，2026-07-30。

**黄金样例实证**：

- `site/electromagnetism/q20-rotating-rod/index.html` 第一问从电荷分离、电势和电流方向衔接到安培力与静力平衡；第二问再由运动状态确定合力、电流和电动势，最后用能量账本解释外力负功，覆盖列式所需的完整桥梁。
- `site/electromagnetism/q21-variable-field-rod-3d/index.html` 四张图直接给出 `v(x)`、`B(x)`、`E(x)`、`Φ(x)` 的位置关系；阶段 A 在 `x=1.5 m` 验证 `F=7.5 N`，阶段 B 解释磁通量不变导致总电动势为零，阶段 D 落到 `E=0.05x`，与题目三个设问逐一对应。

**不及格表现**：模型很直观但学生仍不知道该列什么式；只复述标准答案；公式与动画各占一栏却没有互相指认；只适用于当前数字；通过暴露答案制造“会了”的假象。

**机器可判性**：当前可检查题目设问、模型变量、物理规律、关系式和验证动作是否有可追踪映射，也可验证公式数值；学生是否真正完成从观察到列式的迁移需要老师或学习结果证据。未来可用老师标注的“缺少哪一步列式桥梁”和变式任务表现训练解题衔接判据。

## 使用方式

1. 先通过物理正确性闸门；物理方向、约束、公式或数值错误时不进入六维评价。
2. 老师按六维分别判定“过/不过”并记录原因，不以总分抵消任何一维的明显缺口。
3. 整体结论用于决定是否接受课件；逐维记录用于寻找可复用的机器判据。
4. 同一课件出现稳定分歧时，优先修订本标准的定义或例证，不把分歧直接解释为老师使用错误。
5. “有效信息”是六维共同遵守的元约束而非第七维：信息必须可溯源、对当前任务或判定有用、能与相关量组成显式关系链，并采用与推导链一致的显示精度；不满足者优先删除而非继续解释。（来源：老师首评 `feedback-7d414bc2`，2026-07-30。）

## 产品北极星

长远要做到举一反三、归纳总结，站在出题老师的角色帮学生从根上理解怎么解题。本轮标准和反馈工具只为这条路径建立可比较的数据，不在当前版本实现自动归纳或生成管线拦截。
