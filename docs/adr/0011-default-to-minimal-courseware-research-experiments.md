# ADR 0011：新题默认先做最小研发实验

- 状态：已采纳
- 日期：2026-08-19
- 演进：ADR 0003、0004、0007、0008、0010

## 背景

当前只有一位免费顾问老师和两道题的反馈。q07 得到明确正面意见；q01 被评价为完全吃透题目、整体很好，但处处较重、重点不突出。老师同时明确表示，一两题不足以判断方向。这些证据可以帮助约束下一次实验，不能证明稳定产品形态、学生学习效果、教师付费意愿或商业价值。

既有 harness、九阶段生产主干、生产状态单、逐题冻结和 A0/A1/A2/A3 评审体系解决过生成、恢复与发布中的具体问题，但它们也把尚未验证的规模和流程假设提前固化为默认路径。下一轮首先要验证的是：针对老师真正想试的题，能否以较低治理成本做出有教学价值的互动课件，并获得可解释的真实反馈。

## 决策

1. **下一道真实题默认是研发实验，不是正式生产。** 收到老师想测试的题后，不自动创建 `production/courseware/` 记录，不自动触发 `$build-physics-courseware`，也不要求进入 harness、九阶段状态或 A 级评审。
2. **研发实验采用最短责任链。** 默认顺序为：真实原题 → Codex 物理与教学分析 → 紧凑临时实验任务书 → Kimi Code CLI 前端候选 → Codex 独立检查 → 用户体验与批准 → 稳定老师试用链接 → 老师自由反馈 → 最小实验结论。角色切换、用户批准、发布和外部写入仍是必须停下的真实边界，不把这条顺序实现成新的状态机。
3. **临时实验任务书只服务当前题。** 它只包含原题、物理模型、认知障碍假设、教学干预、互动必要性、必须观察或操控的现象、非目标和可观察验收条件；不沉淀为长期模板、通用 intake 或第二套项目事实源。
4. **四方职责保持分离。** 产品协调 Work 负责跨实验导航、生成单题任务包和汇总结论；单题 Codex 任务负责实验协调、物理与教学契约、Kimi 调用、独立检查和授权边界；Kimi Code CLI 只负责前端候选实现；用户提供题目、亲自体验、连接老师并决定试用、返工、淘汰或转正。
5. **检查与反馈不再服从固定表单。** Codex 必须检查物理、教学、交互、桌面和 iPad 横屏，但检查深度以当前任务书的可观察条件为准。用户体验是老师试用前的产品关口。老师可以自由评价，不要求填写结构化 intake 或六维表单；现有六维标准和评价系统可以提供观察语言与意见入口，但不再是下一轮实验的固定协议。
6. **每轮只长期保留最小实验结论。** 结论包括实际版本身份、老师原意、用户体验、已验证与未验证、继续/返工/淘汰/暂不判断、Token 观察和待复验教学经验。老师原意与用户解释必须分开。调试记录、完整对话、中间候选和临时任务书默认不长期保存。
7. **旧地基保留但暂停默认使用。** `research/generation/` 中的生成器、harness、模板、证据和相关验证代码不删除、不重构、不继续扩张；ADR 0003、0004 与 0007 中关于 harness、预设规模、九阶段生产和 A 级评审的决定不再适用于默认研发实验。ADR 0008 的静态发布、不可变 revision、真实入口和授权边界继续有效。ADR 0010 的老师客户、学生参与者与老师控制权继续有效。
8. **单题经验不能自动改写通用能力。** 一次实验产生的教学或物理经验先记为待复验；只有经过跨题或未见题复验，才在独立任务中更新物理专家 skill、通用模板或长期质量规则。
9. **正式生产必须由用户明确触发。** 只有用户明确决定某题转入正式生产时，才重新评估是否使用 `$build-physics-courseware`、生产状态单、冻结、独立成品评审和不可变发布流程。任何部署、发布、外部写入或生产状态变化仍须重新读取 `BLOCKED.md` 并获得相应授权。

## 结果与限制

- 下一轮实验优先产生外部可观察证据，而不是继续扩建内部治理。
- 研发实验可以使用现有代码和发布基础设施，但“代码存在”不表示必须走其历史流程。
- 暂停默认路径不等于认定旧 harness 或评审体系无价值；是否保留、简化或淘汰，要等最小实验方式真实跑通后再判断。
- 当前不修改 q01、q07、反馈服务、生产记录、部署配置或外部物理 skill。
- Token 作为研发成本观察项保留，不设置会降低整体研发效率的单题硬预算；研发时间不作为记录项。

## 不采用

- **把旧九阶段流程改名后继续作为研发实验默认路径：** 会保留同样的治理成本，无法检验流程减法是否成立。
- **再建设一套轻量状态机或实验总台账：** 会形成新的事实源，并把责任流转误写成产品状态。
- **删除旧脚手架：** 当前没有足够使用证据判断哪些能力应淘汰，删除会混入与本决策无关的代码重构风险。
- **取消物理与成品检查：** 流程减法不等于放弃正确性；检查改为围绕当前题和当前可观察条件，而不是固定等级与通用证据包。
