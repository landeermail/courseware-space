# ADR 0015：最小公开安全边界

- 状态：已接受
- 日期：2026-08-20
- 演进：ADR 0008、0009、0011、0014

## 背景

GitHub Pages 只发布静态白名单，但源仓库本身公开。老师长期入口把访问状态保存在浏览器会话中；如果同一标签页继续进入带第三方脚本的课件，课件脚本也处于同一站点来源。与此同时，公开实验记录曾保存老师逐字反馈，混淆了“可公开课件”和“可公开研发证据”。当前没有发现真实访问码或云端密钥进入 Git 历史，因此本轮不进行紧急下线或大规模迁移。

## 决策

1. **老师入口与课件标签页隔离。** 老师长期入口、“我的反馈”和评价页继续在原标签页中使用既有访问状态；所有“打开、体验、再次体验课件”链接使用 `target="_blank" rel="noopener"`。课件页不接收访问码，既有课件 revision 不修改。
2. **历史评价与稳定链接不变。** 本轮不轮换老师访问码，不改变长期链接字符、任务、历史评价、反馈接口或私有 OSS 对象。
3. **老师逐字证据默认私密。** 真实老师评价对象和逐字原话保存在现有私有评价工作区。公开实验记录只保存证据标识、来源类型和不含身份信息的必要摘要，并与产品解释分开；只有用户明确授权公开时才可写入逐字原话。
4. **保护默认发布分支。** `main` 必须通过 Pull Request 和现有静态校验进入，禁止删除和强制更新；保护规则不得要求当前单人维护者无法提供的外部批准。
5. **不扩大本轮范围。** 不拆分仓库、不迁移域名、不重写 Git 历史、不修改已发布 revision，也不因此暂停下一道题的研发实验。第三方资源本地化、独立老师域名和平台级限流留待后续独立任务评估。

## 结果

- 老师仍从原链接查看历史和提交补充反馈，只会看到课件在独立标签页打开。
- 新实验继续使用同一轻量生命周期，但不再把老师逐字反馈默认发布到公开仓库。
- 发布步骤增加远端分支保护，不改变 Pages URL、工件内容边界或评价服务权限。

## 不采用

- **直接修改474及其他不可变 revision：** 会破坏已发布身份，也不能覆盖同源站点中的其他课件。
- **立即拆分公私仓库或迁移域名：** 影响面超过已确认风险，不属于最小治理。
- **删除当前公开记录后宣称已撤回：** Git 历史可能仍保留内容；是否重写历史需要单独的隐私裁决和授权。
