# ADR 0010：面向老师的可控互动教学工具

- 状态：已采纳
- 日期：2026-08-18

## 背景

ADR 0005 已确定“结构进课件，讲解归老师”，ADR 0006 已确定动态想象层与静态推理层必须追踪同一教学模型；但项目仍把自己概述为“为学生提供互动课件”，没有明确客户、课堂控制权和学生数据边界。产品全生命周期讨论同时出现三种终局：面向学生的自学产品、替老师完成讲解的自动课程，以及由老师组织使用的互动教学工具。

当前只有一位免费顾问老师，尚无真实学生效果、独立老师需求或付费证据。顾问老师对 q07 给出明确正面意见；对 q01 则认为其完全吃透题目但“处处都很重、没有突出”，并明确表示一两题不足以判断产品方向。现有证据可以约束产品边界，但不能支持学生平台、家长付费、减负幅度或商业稳定性的结论。

## 决策

1. **高中物理老师是核心客户。** 老师选择题目和使用时机，组织讲解并判断工具是否有价值；老师个人、学校、教研组或内容平台中谁最终付费继续保持开放。
2. **学生是学习参与者和受益者，不是当前客户。** 首个成熟形态不建设学生账号、画像、学习档案、个性化推荐、家长端或直接面向学生的获客与付费关系。
3. **互动课件是老师控制的教学工具，不是替老师讲完的自学课程。** 老师决定观察、预测、操控、比较、揭示和列式的顺序；产品不得用强制进度、完整自动讲解或固定问题链夺取老师的课堂解说权。
4. **专业教学建议支持老师，不替代老师。** 物理建模、预期认知障碍、问题链、迁移任务和动画约束可以形成教师侧建议或生产输入；学生侧只实现当前互动模型需要的能力，不把全部建议固化为必经流程。
5. **互动课件仍是产品核心。** 纯教学设计助手是另一种产品，不作为 Courseware Space 的替代终局。老师可以提供任何真实想测试的题目，产品不在研发前替老师裁决其需求是否“值得互动”；实际反馈负责揭示产品边界。
6. **能力与商业主张保持诚实。** “减少老师工作量”“让普通老师获得高水平教师的部分能力”“老师会形成稳定付费群体”都是未来价值假设，当前不转化为需求、指标、验收字段或对外承诺。
7. **学生效果仍是独立证据问题。** 老师认可不能冒充学生学会，开发者代理体验不能冒充真实学生行为；但缺少学生证据不触发学生数据平台建设。

## 后果与限制

- 新的交互设计优先提供老师可自由控制的状态、变量、显隐、暂停和比较能力，避免把教学建议编码成不可跳过的学生流程。
- 题库、按题生产服务或二者混合仍是待验证的交付形态；本 ADR 不决定渠道、价格或付费主体。
- 当前只保留不采集学生身份与持续行为数据的产品边界；未来若要进入直接学生产品、个性化学习或家长付费，必须以新证据重新裁决。
- 本 ADR 不修改现有 q01/q07、harness、评价服务或发布机制。新题默认先走最小研发实验、旧生产协议暂停作为默认路径的后续决定见 ADR 0011。

## 不采用

- **当前直接建设学生自学平台：** 会把产品转向账号、学习路径、作业、成绩、家长关系和未成年人数据，而这些能力没有当前证据。
- **把问题链固化成自动课程：** 会与老师争夺课堂解说权，也会让完整性压过老师按班级和现场判断进行取舍的能力。
- **退化为纯教学设计助手：** 虽然有用，但无法承载本项目把不可见物理过程变成可观察、可操控、可验证模型的核心使命。
- **现在定义减负或能力提升指标：** 会把尚未验证的价值假设提前固化为研发管理债务。
