# ADR 0006：动画显化与静态推理双层分工

- 状态：已采纳
- 日期：2026-08-04

## 背景

q01 为补足「与解题的衔接」，连续加入受力图、关系式、考场判断链和分状态页面。静态分析比早期读数堆叠更接近真实解题，但 artifact-first 体验表明：课件逐渐演化成类似 PPT 的静态分镜，原本应帮助学生建立动态想象的动画能力被挤到了边缘。

这不是「动画还是公式」的二选一。产品使命要求显化不可见的物理过程，第六维又要求学生能把观察交接到纸笔解题。缺少任一侧都会重现已经出现过的失败：只有动画时，学生无法复刻推理；只有静态分析时，产品无法打通题目文字和静态图造成的想象鸿沟。

## 决策

同一教学模型分为两个相互约束的层：

1. **动态想象层**负责建立正确的动态表象。动画或直接操控必须显化当前课件假设中的时间演化、状态转折、耦合变化或因果次序，并允许学生观察、预测、操控或验证；自动播放解题步骤、装饰性运动和页面转场不计入该层。
2. **静态推理层**负责形成可复刻的解题结构。受力图、几何图、关系式、系统边界和最短判断链必须让学生能从题设与高中物理规律在草稿纸上重建关键结论；动画状态和机器数值不能成为唯一证明。
3. 两层可以使用独立屏幕或状态分工，但必须追踪同一物理模型和当前状态。对象、符号、下标、方向、颜色角色和关系式含义保持一致；需要跨层查看时提供明确定位，不要求学生靠记忆拼接两套表达。
4. 当课件假设包含过程想象鸿沟时，动态想象层是必需的产品能力。若蓝图认为某题或某个认知任务不需要动画，必须说明缺失表征为何不是时间、耦合或因果过程，并通过蓝图审批；不能因为静态页面更容易实现而默认删去动画。
5. 动态层只保留能改变或检验学习目标相关状态的运动；静态层只保留能参与当前解题判断的信息。两层都服从有效信息与一屏一个认知任务约束。

## 验收含义

- 动态题只有分镜、公式揭示或答案播放，判「过程可见」不通过。
- 动画存在但不能帮助学生预测、操控、比较或验证关键过程，不能作为核心有效交互。
- 静态推理引用的状态、力或变量与动画当前状态不一致，直接判失败。
- 图、文、式对同一物理量使用不同符号或对象归属，直接判失败。
- 通过机器测试只证明结构和状态符合技术契约；动画是否打通动态想象、静态路径是否可复刻，仍须 artifact-first 体验或老师评价。

## 结果

- q01 下一修订不在现有静态页上继续堆料，而是重新划分动态想象任务与静态解题任务；保留已认可的粘性图文同屏布局。
- 生产 Skill 的蓝图必须记录两层分工、共享状态和符号映射；内部验收必须覆盖自由跳转、跨层一致性与动画职责。
- 本 ADR 不规定固定页签、固定动画类型、固定布局比例或具体公式；这些仍由每道题的课件假设和蓝图决定。
