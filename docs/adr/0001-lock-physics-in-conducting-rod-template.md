# ADR 0001：在导体杆模板中锁定物理模型

- 状态：已采纳
- 日期：2026-07-28

## 背景

生成平台 MVP 需要让 AI 把老师输入的题目转换成课件，但模型自由生成公式和方向判断会放大物理错误风险。现有课件表明，滑动导体杆的教学价值来自运动、磁通变化、电流、安培力和能量之间的同步关系，而不是自动生成解题文字。

## 决策

首个模板只覆盖闭合平行导轨上的平动直杆、垂直导轨平面的匀强磁场、定值总电阻和匀速运动。

AI 将来只允许输出模板定义的 JSON 字段。Python 模型负责字段白名单、数值范围、方向判定和物理量推导；确定性渲染器把通过断言的配置填入静态 HTML。AI 不得输出或覆盖物理公式、JavaScript 逻辑或可执行代码。

模板必须同时验证：`E=BLv`、`I=E/R`、`F=BIL`、安培力阻碍相对运动、感应磁场阻碍磁通变化，以及匀速条件下 `Fv=I²R`。

## 结果

- 同一模板可以安全实例化不同数值和方向组合。
- 旋转导体、时变磁场、非匀速动力学、含电源和多杆耦合不在模板范围内，必须进入人工兜底。
- Python 与浏览器各自保留一次物理断言，增加少量重复，但能在生成时和展示时分别阻断配置漂移。
- 扩题型应新增模板或提升模板版本，不通过放宽当前校验来兼容。
