# ADR 0003：从题型模板转向课件生成 harness

- 状态：已采纳
- 日期：2026-07-29
- 演进：ADR 0001（锁定物理于导体杆模板）

## 背景

ADR 0001 用 Python 模板锁死物理、AI 只填参数，换来了导体杆题型的 100% 成功率与物理正确。但这带来一个产品级限制：题型覆盖面被模板数量卡死，每扩一种题型都要人工提炼模板，大模型的生成能力没有被真正使用——正如产品负责人指出的，"依赖模板就失去了大模型的意义"。

产品的真实定位是一个专门面向物理题目课件生成的 AI 工具（harness）：用户通过 skill 或插件触发，harness 把模型的发挥收束到一个稳定范围。这个范围不是"把答案讲得更漂亮"，而是**把题目中不可见的物理过程变成可以观察、操控和验证的时空模型**。

## 决策

从"题型模板"转向"课件生成 harness"：

- 模型获得真正的生成自由，可以产出完整课件代码，不再局限于填写固定模板的参数。
- 物理正确性不靠模板锁死，也不靠模型自觉，而由 harness 的运行时护栏强制保证：
  - 可执行的物理断言库（量纲/单位守恒、公式自洽、能量守恒、楞次定律与右手定则方向一致性、数值范围）；
  - 时空模型原语（可观察、可操控、可验证的载体：时间轴、可调参数、状态读数、过程回放）；
  - 生成→校验→修正的沙箱闭环，断言不过即拒绝并反馈模型重试；
  - 老师对关键物理参数的确认闸（沿用既有后端硬校验）。
- ADR 0001 的导体杆模板降级为 harness 护栏的一个具体实现，不再是被抛弃的弯路，也不再做唯一生产方式。
- 可行性验证范围限定为三种机制差异大的题型：抛体运动、圆周运动、导体杆（对照）。真正新增的是抛体与圆周两种，用于回答"harness 的物理断言库能否在模型自由生成下兜住物理正确"。验证通过后再向更多题型复制，而非一开始铺全。

## 结果

- 产品使命与 harness 定位已写入 `CONTEXT.md`：产品使命、课件生成 harness 两个核心术语。
- 物理正确性的"机器可判"部分（算得对）由断言库兜底，可行性高；"教学是否讲清"等机器难判部分，继续靠老师确认闸与参数显式呈现补。
- 风险：harness 兜不住"教学上是否讲清因果"这类主观质量；若三种验证题型的断言兜底失败，需回到"模板为主、harness 为辅"的混合态并重新评估。
- 后续扩题型的成本从"重新攻关"降为"在已验证的 harness 上复制"，但依赖验证首先成立。
