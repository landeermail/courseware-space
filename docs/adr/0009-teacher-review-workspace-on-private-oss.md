# ADR 0009：以个人长期链接和私有 OSS 承载老师评价工作区

- 状态：已采纳
- 日期：2026-08-13

## 背景

老师长期题库目前用浏览器 `localStorage` 按 `courseware_id` 记录“已评”。q01 v7 的历史评价因此会把正在等待评价的 q01 v8 错标为已评；换设备或清理浏览器后，状态又会丢失。现有 feedback-only 服务只接受匿名六维评价并向私有 OSS 追加 JSON，不支持读取任务、历史评价或修改后的版本。

当前仍是少量合作老师参与的产品开发阶段。需要解决的是：老师使用同一长期链接跨设备看到属于自己的精确 revision 评价任务、历史和修改入口，而不是提前建设账号系统、管理后台或通用数据库。

## 决策

1. **原老师长期链接即当前唯一身份。** 当前只有一位合作老师；老师已经收到的 48 位字母数字凭证保持不变，仍通过长期题库 URL 的 fragment 首次进入。静态页面立即把凭证移入同源 `sessionStorage` 并清除地址栏 fragment，评价 API 对其做精确匹配。部署或内部服务调整不得轮换老师链接；第二位老师出现前不建设多老师映射或账号系统。
2. **任务沿用产品检查点。** 老师评价任务不是新的派发流程，而是既有产品检查点“某位老师评价某个精确 revision”决定的服务端表示。新 revision 不自动产生任务。
3. **OSS 只保存不可变对象。** 每项任务保存为 `feedback/tasks/<teacher_key>/<task_id>.json`，每版评价保存为 `feedback/reviews/<teacher_key>/<task_id>/<feedback_id>.json`。恢复原链接时继续读取已经建立的唯一老师存储键，不复制、覆盖或删除历史对象；任务和评价均只追加。
4. **服务端计算状态与身份。** `GET /api/reviews` 按个人凭证加载任务和评价版本，计算待评价/已评价及当前有效评价；`POST /api/reviews/<task_id>` 从任务对象取得 `courseware_id` 与精确 `revision_id`，客户端不能自行指定。后一版评价指向前一版，旧版保持只读历史。
5. **前端只消费工作区接口。** 题库卡片、“我的评价”和课件内评价入口共享同一任务身份。`localStorage` 只可缓存界面，不能决定任务状态。
6. **不引入数据库。** 当前数量下，私有 OSS 中的不可变 JSON 足以形成历史。接口把存储实现隐藏在 `TeacherReviewWorkspace` 后；未来并发或查询需求显著增长时可以迁移数据库而不改变前端领域契约。
7. **保持评价服务隔离。** 运行包仍不包含模型客户端或 Kimi key。运行角色只允许：向 `feedback/*` 追加 `PutObject`；读取 `feedback/tasks/*` 与 `feedback/reviews/*`；在 bucket 资源上以 `oss:Prefix` 条件仅列举这两个前缀。没有删除、ACL、其他 bucket 或模型权限。
8. **历史迁移不改原证据。** 现有 2026-07-30 q01 评价按产品负责人裁决归属 q01 v7，原文件保留；迁移时新增规范化 v2 评价对象。首批另建立 q01 v8 与 q07 revision `5c8590bd2060` 的待评价任务。

## 结果

- 同一老师换设备打开个人长期链接后，可恢复任务、当前评价和全部历史版本。
- q01 v7 的旧评价不会满足或隐藏 q01 v8 的任务。
- 修改评价不会破坏旧证据；同一任务任一时刻只有一份当前有效评价。
- 当前新增任务只增加对象，不要求覆盖共享索引或建设管理后台；第二位老师出现时另行设计身份与迁移。
- 这次变更涉及个人凭证解释和云端读取权限，真实部署前执行一次有界安全复核；范围仅限跨老师隔离、凭证泄露、OSS 前缀与运行包，不使用无边界安全审查。

## 不采用

- **继续依赖 `localStorage`：** 不能跨设备，也无法区分同一课件的不同 revision。
- **覆盖一个老师的 workspace JSON：** 每次新增任务都要改写旧对象，扩大并发与误覆盖风险；独立不可变任务对象更符合现有追加式边界。
- **立即引入数据库或完整账号系统：** 当前老师与评价规模不足以抵消部署、迁移和运维成本。
- **让客户端提交 revision：** 容易把评价绑定到错误工件；精确 revision 必须来自已分派任务。
- **给运行角色整个 bucket 的读写或列举权：** 超出评价工作区需要，破坏 feedback-only 隔离。
