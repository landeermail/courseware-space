# 老师试用与课件迭代协议

> 本文保留 2026 年 7 月首次校准方法，不是当前单题生产路由。当前开发前模拟教学、蓝图、A0、成品独立试用评审、发布与反馈迭代均以 `$build-physics-courseware` 和精确生产状态单为准。

## 目标与边界

试用不评判老师，也不要求老师现场设计页面。真实闭环是“老师提交题目 → 团队交付可操作课件 → 老师按六维评价 → 按失败维度迭代 → 再次验收”，而不是一次会议结束后停止。

- 参与者：主持人 1 名、高三物理老师 1 名。
- 单题首次沟通与验收建议控制在 60 分钟内；开发与返工时间不计入老师试用时间。
- 不记录姓名、学校、联系方式或其他个人信息。
- 未经产品检查点批准的候选只从本机 `trial/private/` 打开；正式练习课件可公开发布，不把练习题误作保密试题。
- 不展示新题答案和解析，避免先用既有解答锚定课件方案。

## 会前准备

1. 在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`。
2. 确认以下页面能打开：
   - q20：<http://127.0.0.1:8000/electromagnetism/q20-rotating-rod/>
   - q21：<http://127.0.0.1:8000/electromagnetism/q21-variable-field-rod-3d/>
   - 六维打分：<http://127.0.0.1:8000/trial/>
   - 第 1 题课件：<http://127.0.0.1:8000/trial/private/courseware/q01-vertical-circle/>
   - 三道私有题页：`/trial/private/questions/q01-vertical-circle/`、`q03-cut-rope/`、`q11-bubble-chamber/`
3. 为本次试用确定一个匿名会话编号，例如 `trial-20260730-a1`；主持人与老师使用相同编号。
4. 关闭或收起新题答案、解析和其他参考材料。

## 持续工作流

1. **老师提交题目**：保留原题、图、选项和参考解析的来源边界；先独立核对物理，不把参考答案当作模型真值。
2. **团队交付课件**：先明确本题真正难以从文字建立的过程，再选择恰当的模型与交互；不强制套用上一题的页面结构。
3. **老师六维评价**：六维逐项判定 `pass/fail`，失败维必须记录具体缺失；整体是否打回不能抵消任一维的失败。
4. **按维迭代**：失败维的反馈必须落到页面元素、模型状态或解题桥梁；不以装饰性改版替代教学修正。
5. **再次验收**：用原题完成选项解释，再改变一个非本质条件做变式；两者都能沿同一因果骨架解题才算闭环。

## q01 v2 二次评审

本轮只复核首次评价未通过的“过程可见”和“与解题的衔接”，其余维度仍需正常填写，不能因为改动目标集中而默认通过。

1. 从题库进入 `q01-vertical-circle`，先不打开老师审计视图；沿“建模—缓慢推动—撤力—回到选项”完整走一遍。
2. 在缓慢推动中改变 α，观察四个力矢量的方向和长度；特别确认撤力后外力箭头消失且页面明确显示 `F外=0`。
3. 自己完成能量账本，再从账本说出准静态推动的关系式；随后切换撤力过程，用同一四步骨架说出守恒量。
4. 不看源码，仅凭页面说明为什么选 B、D，A、C 分别错在哪；再用“α=12° 提前撤力”检验分析方法能否迁移。
5. 最后打开老师审计视图，任抽三个学生页读数，核对其关系式、当前代入和显示用途是否一一对应。
6. 在评价页提交六维结果；若仍判 `fail`，备注必须指向具体看不清的状态、断裂的关系或无法完成的列式步骤。

交给老师时只附一句：

> 这是按您上次反馈改的第二版，请重点看力箭头和数字推导。

## 首次 60 分钟校准流程（保留作方法记录）

### 阶段零：说明规则（5 分钟）

1. 说明物理正确性是入场券，本次只评价入场券之上的教学质量。
2. 快速读六维名称；不逐条讲解黄金样例，避免主持人的理解先影响老师。
3. 强调“不过”不是否定整个课件，而是指出需要保留的数据和改进方向。
4. 说明校准阶段先独立评价，实战阶段不要求现场设计完整页面。

### 阶段一：校准六维尺度（20 分钟，已完成）

先各自判断，再讨论差异；不要由主持人先给“标准答案”。

### q20（8 分钟）

1. 老师自由操作课件，重点观察第一问因果链、角速度探究和第二问物理时间/能量过程。
2. 老师在打分页逐维选择“过/不过”，失败维度写明缺失环节。
3. 导出 JSON，课件 ID 使用 `q20-rotating-rod`。

### q21（8 分钟）

1. 老师自由操作四个阶段，重点观察位置拖动、同位置比较、阶段 C 往返过程和四张关系图。
2. 用相同尺度逐维判断并导出 JSON，课件 ID 使用 `q21-variable-field-rod-3d`。

### 尺度对齐（4 分钟）

只讨论判断不一致的维度：

- 是标准定义不清，还是课件证据不够？
- 老师实际关注了标准中没有写到的什么？
- 哪个“过”的依据可以复用于其他题，哪个只适用于本题？

标准需要修改时记录原话，不在现场强行统一意见。

### 阶段二：三道新题实战（30 分钟）

每题 10 分钟。主持人展示单题页后只问：

> 这道题的好课件，必须让学生看到什么、做到什么？

不要追问“应该用 2D 还是 3D”“要不要某个按钮”，也不要展示答案。老师回答后，主持人按六维归档原话；某维没有要求就记“未提及”，不要替老师补全。

### 第 1 题：竖直圆环双带电小球

重点保留老师对多物体耦合、缓慢推动过程、库仑力/重力共同作用和能量变化的原始判断。

### 第 3 题：剪绳瞬时动力学

重点保留老师对“剪断前—剪断瞬间”、速度连续性、加速度突变、绳长约束和受力方程的原始判断。

### 第 11 题：气泡室正负电子轨迹

重点保留老师对反应前后粒子、空间方向、曲率随过程变化和动量守恒解释的原始判断，不把原解析中的机制预先告诉老师。

每题使用以下记录骨架：

- 因果呈现：
- 过程可见：
- 有效交互：
- 任务驱动：
- 可验证性：
- 与解题的衔接：
- 老师主动补充但暂不属于六维的内容：

### 阶段三：汇总（5 分钟）

1. 请老师选出最影响理解的三个要求，不按界面实现难度排序。
2. 标记哪些要求在 q20/q21 已经出现，哪些是标准缺口。
3. 区分“所有课件都应满足”的判据和“只适合这道题”的展示方案。
4. 确认记录中没有老师个人信息。
