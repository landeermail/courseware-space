# 单题生产控制面

本目录只服务用户已经明确批准转入正式生产的课件。顾问老师提供的新题默认先做研发实验，不为复用旧协议而在这里建档，也不因需要稳定老师试用链接而自动转入生产。

`production/courseware/<courseware_id>/` 是正式生产课件的唯一恢复模块。新产品协调任务只需读取正式产品知识和该目录即可恢复当前工作，不读取 `trial/private/` 或聊天历史。

每个课件目录分为：

- `record.md`：受版本控制的当前状态、裁决与最小证据引用；
- `input/`：受版本控制、不可替代的规范题面、原始图和当前可复现输入；
- `work/candidate/`：本地可变候选，不纳入 Git；
- `work/evidence/`：本地临时证据，不纳入 Git。

获准发布的精确字节位于 `site/` 的不可变 revision 目录。候选冻结、发布和真实入口核验后，记录应引用该精确目录；不要把已发布字节复制回生产模块。

截图集、完整日志、旧 A0 输出和可以从当前输入与测试重新生成的材料不进入 `input/`。有长期价值的结论写进 `record.md`，其余历史由原所属模块或 Git 历史承担；不得建立平行总索引。
